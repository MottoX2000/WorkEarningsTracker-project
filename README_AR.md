# تطبيق ساعاتي وأرباحي (Android Kotlin + Jetpack Compose) — النسخة المبسطة المبهجة

تطبيق أندرويد بتصميم فاتح ومبهج وبسيط جداً لمتابعة ساعات العمل وعداد المرتب اللحظي، مع وضع تركيز كامل أثناء عد الوقت.

## الميزات الرئيسية
1. **وضع التركيز الكامل أثناء العد:**
   - عند الضغط على **"بدء العمل"**، تختفي جميع العناصر المشتتة ولا يظهر على الشاشة سوى: **عداد المال المتزايد + عداد الوقت + زر الخروج**.
   - عند الضغط على **"خروج"**، تُحفظ الجلسة تلقائياً في سجل اليوم والشهر.
2. **تصميم فاتح مبهج وبسيط:**
   - ألوان فاتحة مريحة للعين ونصوص مختصرة وواضحة بدون ازدحام.
3. **حساب اليوم وإجمالي الشهر (من يوم 1):**
   - بطاقتان مختصرتان لعرض ساعات وأرباح اليوم وإجمالي الشهر من اليوم الأول مع شريط تقدم بسيط.
   - إمكانية إضافة أو تعديل الساعات يدوياً وتخصيص سعر الساعة والعملة في الإعدادات.
